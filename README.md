# Saucedemo-QA-Testing
Manual, API and SQL testing project on SauceDemo
Test Plan: SauceDemo
1. Project Overview
Manual testing of SauceDemo (https://www.saucedemo.com), a practice e-commerce website.

2. Scope
In scope: Login, Product listing and sorting, Cart, Checkout, Logout Out of scope: Performance and security testing

3. Types of Testing
Functional testing
Smoke and regression testing
UI/usability testing
API testing (Postman)
Database testing (SQL)
4. Test Environment
Browser: Google Chrome (latest)
OS: Windows
Test users: standard_user, locked_out_user, problem_user
5. Tools
Excel (test cases), Jira (bug tracking), Postman (API), Chrome DevTools

6. Entry Criteria
Website is accessible and test data is available.

7. Exit Criteria
All planned test cases executed and all bugs reported.

8. Deliverables
Test plan, test cases, bug reports, RTM, API test collection, SQL queries
